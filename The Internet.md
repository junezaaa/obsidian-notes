#### A "nuts and bolt view" (practical, foundation of the subject)

- Billions of connected computing device:
	- Hosts = end systems
	- running network apps at internet [[Network Edge||edge]]
- Packets switches: forward packets (chunks of data)
	- routers, switches
- Comm links
	- fiber, radio, satellite
	- transmission rate: bandwidth
- Networks
	- Collection of devices, routers, link that is managed by an organization
- Internet : network of networks
	- Interconnected ISPs
- Protocols are *everywhere* 
	- control sending, receiving of message
	- ex: HTTP, streaming vid, Zoom, Wifi, IP
- Internet standards
	-  RFC: Request for comments
	- IETF Internet Engineering Task

#### A "service view"
- Infrastructure that provides services to applications
	- Web, social media
- provides programming interface to distributed application
	- "hooks" allowing sending/receiving apps to use Internet transport service
